# 실습과제 1

9페이지의 두 점을 지나는 직선의 방정식 공식을 이용하여 5페이지의 아래 수식을 유도하시오.

힌트 : (Gmin, 0)과 (Gmax, 255)를 지나는 직선의 방정식을 구하면 됨

## 풀이

### 9페이지 공식 — 두 점을 지나는 직선의 방정식

$$y = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1) + y_1$$

---

### 힌트에서 주어진 두 점

$$( x_1,\ y_1 ) = ( G_{min},\ 0 )$$

$$( x_2,\ y_2 ) = ( G_{max},\ 255 )$$

---

### 공식에 대입

$$y = \frac{255 - 0}{G_{max} - G_{min}}(x - G_{min}) + 0$$

$$y = \frac{255}{G_{max} - G_{min}}(x - G_{min})$$

$$y = \frac{255(x - G_{min})}{G_{max} - G_{min}}$$

---

### x = src(x,y), y = dst(x,y) 로 치환

$$dst(x, y) = \frac{src(x, y) - G_{min}}{G_{max} - G_{min}} \times 255$$

---

두 점 **(Gmin, 0)** 과 **(Gmax, 255)** 를 직선의 방정식에 대입하면 히스토그램 스트레칭 수식이 자연스럽게 유도된다.

| 픽셀값 | 변환 결과 | 의미 |
|---|---|---|
| Gmin | 0 | 가장 어두운 값을 완전한 검정으로 |
| Gmax | 255 | 가장 밝은 값을 완전한 흰색으로 |
| 그 사이 값 | 0~255 비율 변환 | 선형적으로 늘어남 |
