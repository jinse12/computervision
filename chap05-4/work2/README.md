# 실습과제 2

히스토그램 스트레칭과 히스토그램 평활화의 차이를 설명하라.

### 히스토그램 스트레칭

히스토그램이 특정 구간에 집중된 영상을 고무줄을 잡아 늘이듯이 픽셀값 전 구간(0~255)에 걸쳐 나타나도록 변환하는 기법이다.

- 변환 함수 : **선형 함수** (Gmin, 0)과 (Gmax, 255)를 지나는 직선

$$dst(x, y) = \frac{src(x, y) - G_{min}}{G_{max} - G_{min}} \times 255$$

- 결과 : 입력 히스토그램이 양 옆으로 늘어난 형태로 변경됨

### 히스토그램 평활화

히스토그램 그래프에서 특정 픽셀값 근방에 분포가 너무 뭉쳐 있는 경우 이를 넓게 펼쳐 픽셀값 분포를 전체 구간에 골고루 나타나도록 변환하는 기법이다.

- 변환 함수 : **비선형 함수** (히스토그램 누적 함수 H(g) 사용)

$$dst(x, y) = round\left( H(src(x, y)) \times \frac{L_{max}}{N} \right)$$

- 결과 : 히스토그램이 전 구간에 골고루 분포하는 형태로 변경됨

### 차이점

| | 히스토그램 스트레칭 | 히스토그램 평활화 |
|---|---|---|
| 변환 함수 | 선형 | 비선형 (누적 함수) |
| 방식 | Gmin→0, Gmax→255로 선형 확장 | 누적 빈도수로 픽셀값 재분배 |
| 결과 | 히스토그램이 양 옆으로 늘어남 | 히스토그램이 전 구간에 골고루 분포 |
| OpenCV 함수 | 별도 제공 없음 (직접 구현) | `equalizeHist()` 제공 |
